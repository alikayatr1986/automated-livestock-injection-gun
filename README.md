# Automated Digital Injection Gun with Livestock Data Storage 🐄💉

An advanced animal injection system designed for domestic and wild animals, featuring precise dosage control and a comprehensive digital database for tracking individual livestock medical histories from birth to end of life.

## 📌 Overview
- Inventor:** Ali Mohammadiounotikandi[cite: 1]
- Patent Number:** WO 2024/165898 A1 (PCT/IB2023/053871)[cite: 2]
- Target Applications:** 
  - Mallein Test in horses[cite: 7]
  - Tuberculin Test in cows[cite: 7]
  - Dehorning drugs in cattle, sheep, and goats[cite: 7]
  - High-precision low-volume veterinary drug delivery (0.1 CC precision)[cite: 4, 7]

---

✨ Key Features & Components
- Digital ID Tracking:** Requires entering the livestock's ear tag ID before every injection to prevent errors and build a complete medical history[cite: 5].
- High Precision Mechanism:** Powered by a 9V battery and controlled via an onboard electronic circuit and dynamic rotating threaded rod[cite: 5].
- Visual Status Indicators:** Red LED (Power ON) and Yellow LED (Injection Mode Ready)[cite: 5].
- Ergonomic & 3D Printed Design:** Elegant, durable plastic body designed via AutoCAD and created using 3D printing technology[cite: 5].
- Cost-Effective:** Uses 2cc carpules allowing up to 20 precise injections per load with replaceable double-sided needle heads[cite: 6].
